# Naresh Cloud / DevOps Portfolio

A responsive GitHub Pages portfolio inspired by the reference design provided by Naresh.

## Files

- `index.html` — portfolio content and structure
- `style.css` — dark/purple/cyan visual design
- `script.js` — mobile navigation, theme toggle and current year
- `assets/Naresh_Aravindhan_Resume.pdf` — add your resume here

## Publish with GitHub Pages

1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your Pages URL.

## Before publishing

Update these links in `index.html`:

- GitHub profile/project URLs
- LinkedIn URL
- Resume PDF filename if different
- Individual project repository URLs
- Email address if needed

The percentage bars are visual portfolio indicators, not formal skill ratings.
